session-pilot

A closed-loop session optimizer for Claude Code and Cowork. It watches your context, tells you in plain language when to act, and hands you the exact command to run.

View on GitHub

Install in two steps

1
Add the marketplace and install the plugin: 
claude plugin marketplace add Thinkelution/session-pilot
claude plugin install session-pilot@thinkelution
2
Start a session and run the guided setup. It asks before changing anything, keeps any status line you already have, and can be undone: 
/session-pilot:setup

What you'll see

A status line that always answers "am I okay?", and alerts that tell you what to do instead of just reporting numbers.

Status line 🟢 31% 🟡 62% · ~9 turns left · 5h 41% 🟠 76% · ~3 turns left · /compact soon 🔴 90% · /compact now Alert, shown directly to you 🟠 Context is 76% full (~3 turns left). Good time to compact: /compact keep: decisions made, open TODOs, file paths, failing tests (handoff saved automatically)

One command for the full picture

/session-pilot:status 🟠 Compact soon — 72% of context used (144k / 200k) Runway: about 4 more turns before it gets critical Cache: 96% of input was served from cache (good) Waste: 0 file(s) re-read often · 0 oversized tool output(s) Mode: balanced · Snooze: off · Status line: on Next step: Compact when this step is done: /compact keep: …

What it does

Context monitorTraffic-light status with a turns-left estimate based on how fast your context is growing.
Auto handoffSaved before compaction and offered to Claude at the next session start in that folder.
Waste detectorFlags repeated file reads and oversized tool output as they happen.
Cache-idle warningWarns when a big context has gone cold and will cost full price to resume.
Direct alertsShown to you, not routed through the model, so they are consistent and never repeated by Claude.
Safe by designHooks only advise and fail open. Setup makes a backup and is fully reversible.

You choose how chatty it is

ModeAlerts atExtras
quiet80% and 90%No waste or idle notes
balanced (default)60%, 75%, 88%Waste and idle notes
proactive50%, 65%, 80%Stricter waste detection

Switch with /session-pilot:mode quiet. Pause everything for a while with /session-pilot:snooze 1h.

Commands

CommandWhat it does
/session-pilot:statusHealth, runway, waste and one next step
/session-pilot:setupGuided status line setup (undo to revert)
/session-pilot:modequiet, balanced or proactive
/session-pilot:snoozePause alerts: 30m, 1h, 4h, off
/session-pilot:handoffWrite a handoff for the next session
/session-pilot:historyRecent sessions, peak context and output
/session-pilot:doctorChecks the install and tells you how to fix problems

Limits

Hooks add advice and show messages; they cannot rewrite your prompts or run /compact for you, so session-pilot recommends and you decide. Zero dependencies; Node 18+. Cowork support depends on its plugin and hook support and is untested.
