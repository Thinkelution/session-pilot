session-pilot

A closed-loop session optimizer for Claude Code and Cowork. It watches your context, flags waste, writes handoffs, and nudges you to compact before quality or cost suffers.

View on GitHub

What it does

Context monitorReads real token usage and advises at 60%, 75% and 88% full.
Auto handoffSaved before compaction and offered at the next session start.
Waste detectorFlags repeated file reads and oversized tool output.
Cache-idle warningWarns when a big context has gone cold and will cost full price to resume.
Status lineModel, context bar and token count at a glance.
HistoryPer-session peak context and output volume.

Install

git clone https://github.com/Thinkelution/session-pilot
claude --plugin-dir ./session-pilot

Status line

{ "statusLine": { "type": "command",
  "command": "node /path/to/session-pilot/scripts/statusline.js" } }

Limits

Hooks only add advisory context and never block. They cannot rewrite prompts or run /compact for you. Zero dependencies; Node 18+.
